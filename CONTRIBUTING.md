# Contributing

Thanks for taking a look. This repo is a write-up of how my shop runs, not the code itself, so the
most useful help is pointing out what is wrong, unclear or out of date.

## Reporting a problem

Open an [issue](https://github.com/nicedreamzapp/how-my-shop-runs/issues/new/choose). The things
that make it quick to fix:

- the section of the README you mean, quoted if it is short
- what is wrong or unclear, and what you expected instead
- for a broken link or image, the link itself and the browser you saw it in

If the problem is in one of the public tools the README links to (moonstone, browser-broker,
claude-screen-to-phone, FiaOS, x402-php or claude-failover), please open the issue in that tool's
own repo.

## Running it locally

There is nothing to install or run. The repo is the README and its images. The shipping
dashboard, the shared brain and the agents are private, because they hold customer data.

## Tests

There are no tests. After an edit, check that the README renders on GitHub, that the mermaid
diagram still draws, and that the links and images load.

## Pull requests

Small and focused is easiest to review: a typo, a broken link, a clearer sentence. For big
changes, open an issue first so we can talk it through. Please do not add screenshots that show
customer names, addresses, emails or order details.

Please follow the [code of conduct](CODE_OF_CONDUCT.md).
