# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: go to the **Security** tab of this repo and click **Report a vulnerability** ([direct link](https://github.com/nicedreamzapp/how-my-shop-runs/security/advisories/new)). Only the maintainer sees the report.

Helpful details: what you found, where you found it (a section of the README, an image, or one of the stores it describes), and how to reproduce it. If an image in this repo shows customer data that should have been covered, say which image and where.

For a problem in one of the public tools the README links to, please report it in that tool's own repo.

I aim to reply within 3 days and to ship a fix or a clear plan within 30 days, depending on severity. You will be credited in the advisory unless you ask not to be.

## Supported versions

This repo has no code, only the README and its images. Fixes go into the latest version on `main`.
